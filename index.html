Gtouch Inclusive Assessment & SkillLink Micro-Credentials Platform

Decoupled Full-Stack Architecture for Special Needs Diagnostics & Labor Market Verification

package: gtouch/iep

The Gtouch Inclusive Assessment & SkillLink Platform is an enterprise-grade, modular software system designed to address critical bottlenecks in special needs diagnosis, competency-based TVET assessment, and labor-market skills verification. Built using Domain-Driven Design (DDD), it combines a high-performance RESTful API backend with a reactive Vue 3 Single-Page Application (SPA), integrating real-time WebRTC tele-consultation, Safaricom M-Pesa automated STK push payments, and cryptographic micro-credential verification.

1. Assessment & Diagnostic Engine

Hierarchical assessment kits partitioned by developmental age brackets, weighted scoring rubrics, automated specialist matching, and automated PDF report generation via wkhtmltopdf.

2. SkillLink Micro-Credentialing

Stackable competency framework generating cryptographic verification hashes and dynamic QR-codes for tamper-proof employer verification of TVET graduate skills.

3. M-Pesa Fintech & Agent Ledger

Seamless STK Push mobile payment rails via custom PHP SDK, automated callback transaction ledgering, and localized affiliate commission distribution for field agents.

4. WebRTC Tele-Assessment & Chat

Real-time peer-to-peer WebRTC video signaling layer for remote specialist consultations, paired with Pusher WebSocket messaging and asynchronous MoveSMS queue dispatching.

5. Kenyan Geographic Hierarchy

Complete multi-tier geographic data model (County → SubCounty → Ward) enabling localized specialist discovery, institution mapping, and regional administration.

6. Domain-Driven Security & RBAC

Laravel Sanctum API token authentication, fine-grained gate policies, and multi-tenant Role-Based Access Control for Admins, Candidates, Guardians, Specialists, and Agents.
